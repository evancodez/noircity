# O3 — people: pedestrians, witnesses, gangs, beat cops, the police system, arrest, the station (lane report, the handover)

Branch `ow/O3-people`, port 5373. Brief: `docs/briefs/O3_PEOPLE.md`. Built on
O1's city (`docs/seams/WORLD.md`); O2 (wheels) and O4 (combat) were not in
main while this lane was built: the brief's calls into them are **stand-ins
behind one seam each** (§4). Review frames: `docs/review/O3/*.jpg` (six).
The proofs: `tools/plays/o3_*.json`, written by `tools/plays/o3/mk.py`, played
by `tools/lib/o3_people.mjs` (real keys, mouse, pad).
