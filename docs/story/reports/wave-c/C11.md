# C11 — the look pass (lane report)

Branch `wave-c/C11-look`, from `wave-c/integration` at 887c23e, port 5351.
The brief is `docs/story/briefs/C11_LOOK.md`: the frames the art director
marked while reviewing the lanes, measured against
`reference/noir_reference.png` and the diner golden
(`shots/golden/diner_settle.png`): hard black, paper white, one light making
pools, nothing an even grey. A picture lane: no rule, collider, AI, timing or
script of any chapter was changed (the one edit in a scene file is a render
value, section 5). This report is the handover.

Tone figures below are `paper white` = luma >= 230, `mid` = 64..191, `ink`
= < 40, in % of a 1440 x 900 frame (`shots/c11/tones.py`, not committed: a
ten-line numpy count). For scale: the reference 5.0 / 30.4 / 50.3, the diner
golden 14.9 / 29.0 / 36.8.
